# Студентська заготовка

HTML і CSS спільної частини готові. Реалізуйте TODO у js/script.js і власний варіант у js/individual.js.

1. Розпакуйте всю папку проєкту.
2. Відкрийте index.html у браузері або через Live Server.
3. Перевірте сторінку за сценаріями методичних вказівок.

Зображення, favicon і локальні шрифти вже включено до assets.
Початково: 1 порція, 2–3 яйця, 1 tbsp масла або олії, 0 із 5 інгредієнтів.
Зміна порцій зберігає позначки; Reset checks очищує лише позначки.
Після перезавантаження стан спільної частини повертається до початкового.
Nutrition наведено на одну порцію та не перераховується.
ШІ використовується лише за бажанням для перевірки власного коду; API не потрібен.
